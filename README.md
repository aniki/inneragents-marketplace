# InnerAgents Marketplace

Public registry of installable agents for the [InnerAgents](https://inneragents.io) Chrome extension.

## How it works

- **`bundles/`** — one `*.inneragents.json` file per agent, imported directly by the extension.
- **`index.json`** — the catalogue fetched by the extension; generated by `generate.mjs`.

## Adding an agent

1. Export the agent from InnerAgents (Settings → Agents → ⬇ Export).
2. Copy the downloaded file into `bundles/`.
3. Fill in the `marketplace` block at the top of the file:

```json
{
  "version": 1,
  "exportedAt": "...",
  "marketplace": {
    "description": "What this agent does — shown on the marketplace card.",
    "icon": "🎵",
    "tags": ["music", "download"],
    "author": "your-github-username"
  },
  "agent": { ... },
  "skills": [],
  "mcpServers": []
}
```

4. Run `node generate.mjs` to rebuild `index.json`.
5. Commit `bundles/<agent>.inneragents.json` and `index.json` together.

## Marketplace URL

Add this URL in InnerAgents → Settings → Marketplace:

```
https://raw.githubusercontent.com/rnanni/inneragents-marketplace/main/index.json
```

## `marketplace` metadata fields

| Field | Description |
|---|---|
| `description` | Shown on the agent card in the marketplace |
| `icon` | Emoji or image URL |
| `tags` | Array of keyword strings for filtering |
| `author` | GitHub username or display name |

The `exportedAt` timestamp serves as the version indicator — no separate semver needed.
