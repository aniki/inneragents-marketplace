Features

Everything you need to build powerful agents

InnerAgents is a complete agentic harness — not a thin wrapper around a chat API.

🔌

Multi-provider LLM

Connect Anthropic, OpenAI, OpenRouter, or any OpenAI-compatible endpoint. Switch models per agent. Pricing displayed directly in the model selector.

🌐

Live browser context

Inject the current page, a screenshot, or a text selection into your conversation with one click. Define URL rules to auto-inject context on specific sites.

⚙️

MCP servers

Connect any remote MCP server over SSE or Streamable HTTP. Bearer token and OAuth 2.0 authentication built in. Your agents gain real tools without code.

🛠

Custom skills

Write JavaScript skills that run sandboxed in the browser. Skills can interact with tabs, capture screenshots, and execute scripts — with your explicit consent.

🧠

Persistent memory

Agents remember facts across conversations. A shared global memory lets all your agents benefit from the same user context. Everything stored locally.

🤝

Multi-agent collaboration

Delegate subtasks to specialized agents. A research agent hands off to a writing agent, which hands off to a publishing agent. Full delegation trace included.

Get started

Up and running in 3 steps

No account, no setup wizard. Just your API key and a first message.

1

Add a provider

Paste your Anthropic, OpenAI, or OpenRouter API key in Settings → Providers. Your key is stored locally and never leaves your device except to call the model.

2

Create an agent

Give your agent a name, a system prompt, and pick a model. Optionally attach MCP servers or skills. Import a ready-made agent from the Marketplace in one click.

3

Start chatting

Open the sidebar on any page. Inject the page content, paste a screenshot, or ask a question. Your agent has full access to the tools you gave it.

Compatible providers

Bring your own API key

🟣 Anthropic (Claude)
🟢 OpenAI (GPT / o-series)
🔵 OpenRouter
⚪ Any OpenAI-compatible endpoint
🔒

Local-first, always

Your conversations, API keys, and agent configurations are stored on your device — in chrome.storage.local and IndexedDB. InnerAgents has no backend, no analytics, and no account system. Your data is yours.
